# XTCP UL 连续进展证据分析（A2）

这是独立、只读的离线诊断工具，不接入或放宽已有 qualification / strict v3 门禁，不改变 C++ 数据面。用户在本轮明确要求主代理直接实现 A2；A1 模块复用且未修改。

## 使用

```sh
python3 tools/xtcp_ul_stall_report.py /path/to/iperf-ul-p4.json
python3 tools/xtcp_ul_stall_report.py /path/to/iperf-ul-p4.json --stall-seconds 3
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests/tooling -p 'test_xtcp_ul_stall*.py'
```

输入是 **UL client 的完整 TCP iperf JSON**，不是 server/client 配置 JSON，也不是混合 NDJSON。结果写到 stdout；工具不写输入文件、不修改历史结果。

| status | 退出码 | 含义 |
|---|---:|---|
| `no_observed_stall` | 0 | 完整证据中未观察到达到阈值的连续零字节区间 |
| `observed_stall` | 1 | 至少一条流的连续零字节观测达到阈值 |
| `not_assessed` | 2 | 参数错误、证据缺失、不支持的采样角色或内部矛盾 |

默认阈值为 2 秒，必须是正有限数；判断使用 `>=`，不把不足阈值的时间四舍五入成停顿。`--help` 为普通文本帮助，不是分析结果。

## 输入与完整性契约

- 复用 A1 的严格 JSON、数值类型、UL方向和连接身份校验。区间及结束汇总必须明确标记 `sender: true`；缺失角色不推断为发送端。
- 根据 socket 标识关联流，不依赖流在数组中的位置。每个区间必须包含全部且唯一的已连接流；每个流必须有唯一 sender 结束汇总。
- 每条区间显式提供布尔 `omitted`。预热区间排除后处理测量计时重置；开始正式测量后再出现 omit 视为无效。
- 区间 `start/end` 为时间依据，`bytes` 为字节依据，不用冗余 `seconds/bits_per_second` 字段重建时间或字节。时间必须可用有限浮点数表达；字节必须为 uint64 范围内非负整数。
- 同流区间按输入顺序递增，不自动排序修复；内部间隙/重叠绝对容差为 **1 微秒**。首尾与配置时长的边界容差为 **1 毫秒**；区间尾与该流结束汇总尾相差不得超过 1 微秒。不使用随时间值放大的相对容差。
- 首尾要与结束汇总及配置 duration 相符；各流须覆盖共同的测量窗口（首尾差异不超过 1 毫秒）。逐区间非omit字节总数必须等于 sender 结束汇总。无结束汇总、缺首尾/缺流、字节不一致均未评估，不拼补数据。
- 本契约针对按时间结束的完整测试；缺少正 duration 的字节数/块数限额测试不支持。非常短或定时抖动明显的历史测试可能不满足这些严格边界。

## 停顿与公平性

每流报告有效字节、按区间时长求和的测量时长、平均 B/s、最长连续零字节观测、零字节区间及是否达到阈值。合并连续零区间时不计入容差内的小空隙，也不重复计算容差内的重叠。

总体 Jain 指数基于完整测量窗口内各流的平均 B/s，不由总吞吐推断公平性。区间 Jain 只在各流区间数量相同、对应边界在 1 微秒内对齐且有公共交集时计算；否则 `fairness.interval_status=not_assessed`，不插值、不按下标强行对齐。所有流均零字节时 Jain 为 `null`（0/0 未定义），不是 1。

区间公平性未评估不自动使完整的每流停顿观测失效；区间完整性失败则整个报告未评估，不输出部分成功。Jain 是观测值，没有额外发明“公平性通过”阈值。

## 证据边界

本工具只能说明发送端采样区间内观察到的字节进展。它不证明接收端交付、应用一直有待发送数据、预算死锁或 strand/pacing 根因；正字节区间内部仍可能有采样粒度看不见的短停顿。没有把不同时间基准的全局 stats 与单流时间强行关联。

历史回看保存在 `artifacts/g6-a2-validation-0908/historical-reports.json`。8份样本中，旧 P1 观察到 3.000133 秒连续零字节；其余7份因首尾或字节汇总不符而未评估。修复后样本存在一个或多个131072字节块的区间/结束汇总差异，以及毫秒级时长差异；这些差异的来源尚未确定，**不能据此认定数据丢失或回归**，也没有修改样本或放宽门禁以获取通过。

A2 完成不代表 B 长时实验或 C 数据面优化完成。后续 B 必须先确认采样完整性契约与新采集证据相符，再建立每流持续发送需求和时钟关联；不得把未评估报告当作成功。
